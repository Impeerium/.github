# Organization profile

This is the public `Impeerium/.github` repository. Its default branch is `main`.

- GitHub renders `profile/README.md` on the public organization Overview.
- Use the existing emerald crown and palette. Keep images accessible with descriptive alt text.
- Keep the public profile about the community. Private project directories belong in `Impeerium/.github-private`.
- Do not add live server metrics, version claims or season availability without current evidence.
- Check Markdown rendering, links and SVG appearance before pushing. There is no plugin build or server deployment for this repository.
- Root community-health files and issue templates can affect other repositories; only add them when that behavior is intended.
