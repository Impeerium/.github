# Impeerium on GitHub

The public profile and visual assets for the [Impeerium organization](https://github.com/Impeerium).

- [`profile/README.md`](profile/README.md) appears on the organization's public Overview page.
- [`profile/assets/impeerium-banner.svg`](profile/assets/impeerium-banner.svg) is the shared emerald banner.
- [`profile/assets/impeerium-crown.png`](profile/assets/impeerium-crown.png) is Impeerium's existing crown, sourced unchanged from the community website.

Edit the profile on `main` to update the public organization page. Use absolute asset URLs in the profile so images work from the organization Overview as well as this repository. The banner embeds the crown to remain self-contained when displayed as an SVG image.

The separate, private `Impeerium/.github-private` repository holds the member-only project directory. Keep private project details there.

Community links: [website](https://impeerium.net/) · [Discord](https://discord.impeerium.net/).
